# Data and Publication Policy

## Purpose

This repository is intended to document computational methodology,
software development, reproducible workflows, and technical learning
associated with an undergraduate research project involving L-carnosine.

It is not intended to serve as the primary storage location for
unpublished research data.

## Default Rule

Research material should be considered private unless it has been
explicitly reviewed and approved for public release.

When in doubt, do not commit the file.

## Material That May Be Public

The following types of material may be included when they do not reveal
unpublished research results:

- Python source code developed for analysis and automation;
- generic ORCA input templates;
- workflow documentation;
- software usage notes;
- sanitized examples;
- synthetic or demonstration datasets;
- tests and testing fixtures;
- generic visualization scripts;
- documentation about computational validation and reproducibility.

## Material That Should Remain Private by Default

The following material should not be committed without explicit review:

- complete ORCA outputs from active research calculations;
- optimized molecular geometries from unpublished calculations;
- research-specific molecular structures or protonation states;
- calculated vibrational frequencies and IR intensities;
- unpublished spectra;
- energetic comparisons between structures;
- scientific interpretations not yet reviewed by the advisor;
- files or results provided by the advisor;
- unpublished experimental data;
- internal research notes or meeting records;
- figures containing unpublished scientific results.

## Local Research Storage

Current research calculations are stored outside this Git repository.

Local directories containing active research calculations must remain
separate from the version-controlled project.

Research calculation directories must not be copied wholesale into this
repository.
